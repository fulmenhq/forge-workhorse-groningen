# Release 0.1.10 (2026-01-29)

Patch release enabling full JSONSchema draft support for CDRL users, with documentation and test coverage demonstrating multi-flavor schema validation.

## Overview

- **Multi-draft schema validation**: Supports Draft-04, Draft-06, Draft-07, Draft 2019-09, and Draft 2020-12
- **Auto-detection**: Schema draft determined automatically from `$schema` field
- **Meta-validation**: Validate your schemas are well-formed before deployment
- **CDRL-ready**: Downstream users inherit all capabilities with no configuration

## Feature: Full JSONSchema Flavor Support

CDRL users can now use any major JSONSchema draft in their applications:

| Draft         | `$schema` URI                                  | Status    |
| ------------- | ---------------------------------------------- | --------- |
| Draft-04      | `http://json-schema.org/draft-04/schema#`      | Supported |
| Draft-06      | `http://json-schema.org/draft-06/schema#`      | Supported |
| Draft-07      | `http://json-schema.org/draft-07/schema#`      | Supported |
| Draft 2019-09 | `https://json-schema.org/draft/2019-09/schema` | Supported |
| Draft 2020-12 | `https://json-schema.org/draft/2020-12/schema` | Supported |

This enables integration with external systems using legacy schema formats without requiring manual configuration or workarounds.
